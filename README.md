# 🛡️ Content Guardian — חוסם תוכן וצניעות ל-Chrome

תוסף Chrome (Manifest V3) שחוסם **הרמטית את X (טוויטר)** ואתרי **תוכן לא צנוע**,
עם **אימות מול חשבון ה-Google** המחובר בדפדפן כתנאי להפעלה.

---

## ✨ מה התוסף עושה

| רכיב | תיאור |
|------|-------|
| **חסימת X / טוויטר** | חסימה ברמת הרשת (`declarativeNetRequest`) של `twitter.com`, `x.com`, `twimg.com` (תמונות/וידאו) ו-`t.co` (קיצור כתובות) — כולל כל תתי-הדומיינים, **עוד לפני שהאתר נטען**. |
| **חסימת תוכן לבוגרים** | רשימת דומיינים ידועים + חסימה חכמה לפי סיומות (`.xxx`, `.porn`, `.adult`…) ומילות מפתח בשם הדומיין. |
| **אימות Google** | זיהוי אימייל המשתמש המחובר לדפדפן דרך **Chrome Identity API**; החסימה מופעלת רק עבור משתמש מורשה. |
| **דף חסימה מעוצב** | `blocked.html` — עמוד נקי ומעוצב שמוצג במקום האתר החסום, עם הסבר על סיבת החסימה. |

## 🚀 התקנה במצב מפתח (Developer Mode)

1. פתחו בכרום את הכתובת: `chrome://extensions`
2. הפעילו למעלה מימין את המתג **"מצב מפתח" / "Developer mode"**.
3. לחצו על **"טעינת תוסף לא ארוז" / "Load unpacked"**.
4. בחרו את התיקייה של הפרויקט (זו שמכילה את `manifest.json`).
5. התוסף יופיע ברשימה — נעצו אותו לסרגל הכלים (אייקון 🛡️).
6. לחצו על האייקון → **"אימות מול חשבון Google"** כדי להפעיל את החסימה.

> לבדיקה: נסו לגלוש ל-`https://x.com` — אמורים להיות מופנים אוטומטית ל-`blocked.html`.

## ⚙️ הגדרות

### הגבלה למשתמשים מורשים בלבד
כברירת מחדל כל משתמש Google מחובר מורשה. כדי להגביל, ערכו ב-`background.js`:

```js
const AUTHORIZED_EMAILS = [
  "raphael010289@gmail.com",
];
```

אם הרשימה ריקה (`[]`) — כל חשבון Google מחובר יורשה.

### הוספת אתרים לחסימה
ערכו את `rules.json`:
- הוסיפו דומיין למערך `requestDomains` בחוק המתאים.
- לאחר עריכה, לחצו **"רענון" (↻)** על התוסף בעמוד `chrome://extensions`.

## 🔐 על אימות Google (Chrome Identity API)

התוסף משתמש בשתי שכבות:

1. **`chrome.identity.getProfileUserInfo`** — מזהה את האימייל של חשבון הדפדפן
   ללא צורך בהסכמת OAuth (עובד מיד לאחר ההתקנה).
2. **`chrome.identity.getAuthToken`** (אופציונלי, אימות חזק יותר) — דורש
   הגדרת **OAuth Client ID** אמיתי:
   - היכנסו ל-[Google Cloud Console](https://console.cloud.google.com/) → APIs & Services → Credentials.
   - צרו **OAuth client ID** מסוג *Chrome Extension* עם ה-Extension ID שלכם.
   - הדביקו אותו ב-`manifest.json` תחת `oauth2.client_id`.

> אם אינכם צריכים אימות OAuth חזק — ניתן להשאיר את ה-`client_id` כפי שהוא;
> התוסף ייפול חזרה לזיהוי חשבון הדפדפן והחסימה תפעל כרגיל.

## ⚠️ מגבלה חשובה (שקיפות מלאה)

תוסף דפדפן הוא **סינון עצמי/הורי מרצון**, לא מנגנון אבטחה בלתי-עקיף:
מי שהתקין את התוסף יכול גם לכבותו או להסירו דרך `chrome://extensions`.
לאכיפה חזקה יותר שקלו שילוב עם ניהול פרופיל (Chrome Enterprise Policy)
או פתרון סינון ברמת הרשת/הראוטר.
