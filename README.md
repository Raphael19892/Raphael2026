# FiberTrack 🌾 — יומן סיבים תזונתיים חכם

אפליקציית React Native (Expo) למעקב אחר צריכת סיבים תזונתיים, עם ניתוח
ארוחות מבוסס LLM ותובנות מדעיות מבוססות מחקרים קליניים.

## רכיבי הליבה

| רכיב | קובץ | תיאור |
|------|------|-------|
| יומן תזונה חכם | `src/components/MealLogInput.tsx` + `src/services/aiAnalysis.ts` | הזנת ארוחה בטקסט חופשי; ה-LLM (OpenAI Function Calling) מפרק אותה לפריטים ומעריך סיבים מסיסים, בלתי-מסיסים ועמילן עמיד |
| מנוע "האם זה בריא לי?" | `src/services/healthAssessment.ts` | ציון 0–100 דטרמיניסטי: יעד WHO (30+ גרם), יחס מסיס/בלתי-מסיס, עמילן עמיד ומגוון פרה-ביוטי למיקרוביום, וגיוון צמחי |
| תצוגת תובנות מדעיות | `src/screens/DashboardScreen.tsx` + `src/components/InsightCard.tsx` | דשבורד עם טבעת ציון יומי, פירוק סוגי סיבים ותובנות בשפה פשוטה עם אסמכתאות (Lancet 2019, mSystems 2018 ועוד) |

## ארכיטקטורת הניתוח

```
טקסט חופשי → SYSTEM_PROMPT תזונתי → tool_choice: log_fiber_analysis
           → JSON מובנה (פריטים, סוגי סיבים, תרכובות פרה-ביוטיות, תובנה)
           → נרמול וולידציה (normalizeAnalysis) → יומן → מנוע הערכה → דשבורד
```

הציון הבריאותי מחושב **מקומית ודטרמיניסטית** — ה-LLM אחראי רק על פירוק
הארוחה והתובנה המילולית, כך שהציון עקבי וניתן להסבר מלא (`breakdown`).

## הרצה

```bash
npm install
cp .env.example .env   # והזינו מפתח OpenAI או כתובת proxy
npm start              # Expo Dev Server; סרקו QR עם Expo Go
```

## הערת אבטחה

בפרודקשן אין לשמור מפתח API בקוד הלקוח. הגדירו
`EXPO_PUBLIC_LLM_PROXY_URL` לשרת-ביניים שמוסיף את ה-Authorization בצד
השרת, ומחייב אימות משתמשים.
