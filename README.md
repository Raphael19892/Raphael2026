# 🛡️ Content Guardian — חוסם X ותוכן לא צנוע

תוסף Chrome פשוט (Manifest V3) שחוסם **הרמטית את X (טוויטר)** ואתרי **תוכן לא צנוע**.
**טוענים לדפדפן וזה עובד מיד — בלי שום הגדרה.**

---

## 📁 קבצים

```
manifest.json   # הגדרות התוסף
rules.json      # רשימת החסימות
blocked.html    # דף החסימה
blocked.js      # לוגיקת דף החסימה
```

---

## 🚀 התקנה (במחשב)

1. הורד את הקבצים וחלץ אותם לתיקייה.
2. פתח ב-Chrome: `chrome://extensions`
3. הפעל למעלה מימין **"מצב מפתח" / Developer mode**.
4. לחץ **"טעינת תוסף לא ארוז" / Load unpacked** → בחר את התיקייה עם `manifest.json`.
5. **זהו.** נסה להיכנס ל-`x.com` — תופנה אוטומטית לדף החסימה.

### 📱 אנדרואיד (דרך Kiwi Browser)
Chrome הרגיל בנייד לא תומך בתוספים. באנדרואיד השתמש ב-**Kiwi Browser** (חינמי):
`kiwi://extensions` → Developer mode → Load → בחר את התיקייה. **אייפון לא נתמך.**

---

## 🚫 מה נחסם

- **X / טוויטר (הרמטי):** `twitter.com`, `x.com`, `twimg.com`, `t.co` וכל תתי-הדומיינים — כולל תמונות, וידאו, סקריפטים ו-API.
- **תוכן לבוגרים:** רשימת אתרים ידועים + זיהוי חכם לפי סיומות (`.xxx`, `.porn`…) ומילות מפתח בשם הדומיין.

## ➕ הוספת אתרים לחסימה
ערוך את `rules.json` — הוסף דומיין למערך `requestDomains`, ואז לחץ **רענון (↻)** על התוסף ב-`chrome://extensions`.

---

> ℹ️ תוסף דפדפן הוא סינון מרצון — מי שהתקין אותו יכול גם לכבותו. לאכיפה חזקה יותר שקול DNS מסנן (NextDNS) או שליטה הורית ברמת המכשיר.
