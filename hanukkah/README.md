# 🕎 עולם החנוכה – Hanukkah Kids

אפליקציית חנוכה אינטראקטיבית לילדים בגילאי 4–10. היא בנויה ב-HTML, CSS ו-JavaScript בלבד, בלי שרת ובלי קבצי תמונה או סאונד: כל האיורים מצוירים ב-SVG וכל הצלילים והמוזיקה נוצרים בזמן אמת.

## מה יש באפליקציה
| אזור | תוכן |
|---|---|
| 🏠 מסך הבית | חנוכייה מוארת ומונפשת, מד התקדמות, כפתור "התחילו לשחק" שמוביל לפעילות הבאה במסע |
| 🎮 7 משחקים | הדלקת נרות (8 לילות, לפי סדר ההלכה), סביבון תלת־ממדי (נ־ג־ה־פ), חידון (2 רמות), משחק זיכרון (3 רמות), מצא את ההבדלים (3 רמות), איסוף מטבעות – משחק ריצה (3 שלבים), פאזל (3 תמונות) |
| 📖 5 סיפורים | החשמונאים, מתתיהו ובניו, יהודה המכבי, נס פך השמן, ניצחון האור על החושך. בכל סיפור 5 פרקים מאוירים, קריינות ושאלת בונוס בסוף |
| 📜 לימוד | 6 נושאים, וכל קטע מסומן: **הלכה / מנהג / סיפור / מקור / רעיון**. יש גם שאלות ותשובות בכרטיסים הפוכים |
| 🏆 הישגים | כוכבים, 7 מדליות, שלבים שנפתחים בהדרגה, אוסף אותיות הסביבון, ותעודת "אלוף החנוכה" עם שם הילד (אפשר לשמור אותה כתמונה) |
| 🔊 סאונד | מוזיקת רקע עדינה (לחן מקורי), אפקטים קוליים, וקריינות בעברית דרך מנוע הדיבור של המכשיר |

ההתקדמות נשמרת במכשיר עצמו (localStorage). האפליקציה היא PWA: אפשר להתקין אותה במסך הבית באנדרואיד, ואחרי הטעינה הראשונה היא עובדת גם בלי אינטרנט.

## הפעלה בטלפון אנדרואיד
1. ב-GitHub: **Settings ← Pages ← Source: Deploy from a branch**. בוחרים את הענף ואת התיקייה `/ (root)` ושומרים.
2. בטלפון, פותחים ב-Chrome את הכתובת `https://<user>.github.io/<repo>/hanukkah/`.
3. בתפריט ⋮ בוחרים **"הוספה למסך הבית"** או **"התקנת אפליקציה"**.

> קריינות: אם לא שומעים קול, צריך להתקין "עברית" ב-Google TTS. ההגדרה נמצאת בטלפון תחת: שפה וקלט ← המרת טקסט לדיבור.

## הרצה מקומית
```bash
cd hanukkah
python3 -m http.server 8000
# ואז לפתוח בדפדפן: http://localhost:8000
```

## מבנה הקבצים
```
hanukkah/
├── index.html            – נקודת הכניסה
├── manifest.webmanifest  – התקנה כאפליקציה
├── sw.js                 – עבודה בלי אינטרנט
├── css/style.css         – העיצוב
├── icons/                – אייקוני האפליקציה
└── js/
    ├── art.js            – כל האיורים (SVG)
    ├── core.js           – שמירה, צלילים, מוזיקה, קריינות, אפקטים
    ├── content.js        – סיפורים, לימוד, שאלות החידון
    ├── games1.js         – נרות, סביבון, חידון, זיכרון
    ├── games2.js         – הבדלים, ריצה, פאזל
    └── app.js            – מסכים, ניווט, הישגים ותעודה
```
