# סיכום הלכות ריבית – אפליקציית לימוד

אפליקציית ווב (PWA) לספר "סיכום הלכות ריבית" (יו"ד סימנים קנ"ט–קע"ז) מאת שמואל אהרון ברוכיאן.

- **תוכן עניינים** – כל הסימנים, הסעיפים והנושאים, עם מספרי העמודים בספר.
- **קריאה** – טקסט מלא, ציטוטי גמרא מודגשים, פסקי השו"ע והרמ"א מסומנים, שינוי גודל גופן, מצב כהה, פס התקדמות.
- **המשך מהמקום שעצרת**, סימון פרקים כנלמדו ושמירת נושאים.
- **חיפוש** בכל הספר, ו**פסקים** – כל פסקי השו"ע במקום אחד לחזרה.
- עובד גם ללא רשת לאחר טעינה ראשונה, וניתן להתקנה על מסך הבית.

קבצים: `index.html` (האפליקציה), `book.json` (תוכן הספר), `app.html` (המקור; `./build.sh` מייצר ממנו את `index.html`), `build_data.py` (חילוץ התוכן מה-PDF).
