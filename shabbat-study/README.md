# לימוד הלכות שבת, סעיף אחר סעיף

כלי לימוד לפי השולחן ערוך אורח חיים. הוא לא פוסק הלכה. לשאלה מעשית, שאל רב.

## איך מפעילים (ב-Claude Code)
פותחים את המאגר ב-Claude Code וכותבים:

`הכן את סימן N`

(N הוא מספר הסימן. את הסימן הראשון של הלכות שבת בוחרים לפי תוכן העניינים של השולחן ערוך ב-Sefaria.)

הסוכן הראשי מפעיל לפי הסדר: מביא מקורות, מסביר, בודק, מכין שאלות. אחר כך הוא עוצר ומציג סיכום. רק אחרי שאתה מאשר, הסימן עובר לתיקיית `content`.

## מבנה הקבצים
- `CLAUDE.md` הוראות הסוכן הראשי.
- `.claude/agents/` ארבעת תת-הסוכנים.
- `shabbat-study/work/siman-N/` קבצי עבודה שעדיין לא אושרו: `source.json`, `explanation.json`, `verification.json`, `quiz.json`.
- `shabbat-study/content/siman-N.json` סימנים שאושרו על ידי המשתמש (אלה שיוצגו באפליקציה).
- `shabbat-study/progress.json` אילו סימנים אושרו (נוצר אחרי האישור הראשון).

## מבנה קובץ מאושר
```json
{
  "siman": 0,
  "title": "",
  "url": "",
  "seifim": [
    { "seif": 1, "text": "", "explanation": "", "key_terms": [] }
  ],
  "quiz": [],
  "approved_by_user": true,
  "disclaimer": "לשאלה מעשית, שאל רב"
}
```

## כללים
- אין להעתיק ל-`content` בלי אישור מפורש.
- אין להמציא נוסח. אם Sefaria לא נגיש, עוצרים ומדווחים.
- ההסברים נבדקים מול הנוסח, אבל גם אחרי הבדיקה כדאי שאדם יקרא אותם לפני שמסתמכים עליהם.

## השלב הבא
אפליקציה שקוראת את `content/` ומציגה סימן אחד בכל פעם עם שאלות חזרה ומעקב התקדמות.
